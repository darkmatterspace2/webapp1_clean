🔍 1. Core Boolean & Syntax Rules
Operator Syntax Example Description & Engine Support
"..." (Exact Phrase) "quantum computing architecture" Forces strict character and word-order match without synonym expansion.
- (Exclusion) python -wikipedia -youtube Excludes pages containing the keyword or domain. No space after minus!
OR / | (rust OR golang OR python) Matches either term. Must be uppercase in Google/Bing.
( ... ) (Grouping) (site:github.com OR site:gitlab.com) "docker" Combines complex boolean logic operations.
* (Wildcard) "the * of artificial intelligence" Matches any word or sequence between terms (Google, Bing, Yandex).
.. (Number Range) camera $300..$700 or tesla 2020..2025 Matches numbers, prices, or years within a given interval.
AROUND(n) (Proximity) "OpenAI" AROUND(4) "Anthropic" Finds pages where terms appear within n words of each other (Google, Yandex /n).
🌐 2. Location & Structural Target Operators
Operator Syntax Example Description
site: / -site: site:arxiv.org / -site:pinterest.* Restricts or excludes entire domains, subdomains, or TLDs.
filetype: / ext: filetype:pdf "machine learning" Limits search to specific document/data extensions (pdf, docx, xlsx, json, sql, etc.).
inurl: / allinurl: inurl:/.git/config or allinurl:admin login Finds keywords located in the page URL path.
intitle: / allintitle: intitle:"index of /" Matches strings inside the HTML <title> tag.
intext: / allintext: intext:"API_KEY" Restricts matching to the body text of the webpage.

🛠️ 4. Developer Guide: Adding Custom Dorks & Presets in JS

All exclusion rules, dork templates, and search engine definitions are cleanly declared in standalone JavaScript objects at the beginning of the <script> block:

// 1. Add a new Dork Template to DORK_TEMPLATES: { id: "my_dork", category: "cloud", // open_dir | academic | cloud | leaks | webcam | media | code | anti_spam name: "Custom S3 Leak Hunt", desc: "Locates public Amazon S3 buckets with backups", template: 'site:s3.amazonaws.com "backup" "KEYWORD"' } // 2. Add a new Preset to PRESETS_CONFIG: { id: "custom_preset", name: "Exclude AI Content Generators", icon: "🤖", category: "web", defaultActive: false, domains: ["civitai.com", "midjourney.com", "nightcafe.studio"], tooltip: "Strips AI generative platforms" }
