OmniSearch Pro: User Manual & Developer Guide
🚀 Quick Start Guide

OmniSearch Pro transforms your search query into optimized, engine-specific URL structures with granular resolution filters, domain exclusion presets, filetype constraints, and deep-web operators across 15+ independent and uncensored search engines.

  1. Type keywords in the top search bar (e.g. milkyway galaxy or climate report).
  2. Select your search mode (Web, Images 8MP+, Videos, Documents, or Dorks).
  3. Toggle Preset Chips to instantly strip mainstream video sites, stock photo watermarks, or SEO content farms.
  4. Click "Launch All" to open every engine simultaneously in tabs, or click any individual engine card to inspect and copy the exact generated URL.

🖼️ Image Resolution & Filter Logic

When searching images with resolution filters (e.g., 8MP), OmniSearch Pro synthesizes native engine query parameters:

Google: &tbm=isch&tbs=isz%3Alt%2Cislt%3A8mp (Minimum 8 MegaPixels / 3264x2448) Bing: &qft=+filterui:imagesize-custom_3840_2160+filterui:photo-photo Yandex: &isize=large&itype=png SearXNG: &categories=images
🛠️ Developer Guide: Adding & Customizing Presets in Code

All exclusion rules and search engines are declared in clean JavaScript data structures at the beginning of the script. To add your own custom preset, simply add an object to PRESETS_CONFIG:

// Example: Adding a new preset to PRESETS_CONFIG { id: "exclude_ai_art", name: "Exclude AI Art Sites", icon: "🎨", category: "images", defaultActive: false, domains: ["artstation.com", "deviantart.com", "midjourney.com", "civitai.com", "nightcafe.studio"], tooltip: "Strips AI image generator showcases" }

To add a new search engine, simply add an entry to ENGINES_CONFIG with its buildUrl() handler!
